# Plan: Phase 1 - Design System Foundation & Global Navigation

## Goal
Establish TailwindCSS, shadcn/ui utilities, centralized CSS variables in `global.css`, Lucide icons, Framer Motion, and the responsive floating navbar for Fifteen Miles & Atlas.

## Depends on
- None (First phase)

## Requirements Covered
- **CORE-01**: Implement design system foundation using TailwindCSS, shadcn/ui, and centralized CSS variables in `global.css` (Dark mode first, minimal, elegant, Apple/Stripe/Linear aesthetic).
- **CORE-02**: Build responsive floating navbar with glass blur effect, navigation links, and explore CTA.

## Tasks

### Task 1: Install Dependencies & Configure Tailwind / shadcn styling
- **read_first**: `package.json`, `vite.config.ts`
- **action**: Install `tailwindcss`, `postcss`, `autoprefixer`, `lucide-react`, `framer-motion`, `clsx`, `tailwind-merge`, `class-variance-authority`. Initialize Tailwind configuration and setup `src/index.css` (or `global.css`) with Apple/Stripe/Linear dark mode CSS variables (`--background`, `--foreground`, `--primary`, `--muted`, `--border`, etc.).
- **acceptance_criteria**:
  - TailwindCSS and PostCSS are configured and compiling.
  - Lucide icons, Framer Motion, and clsx/tailwind-merge are installed.
  - `global.css` contains centralized semantic CSS variables for dark-mode-first premium aesthetic.

### Task 2: Build Reusable UI Primitives & Floating Navbar
- **read_first**: `src/App.tsx`, `src/index.css`
- **action**: Create core reusable components (Button, Container, Navbar) adhering to shadcn/ui patterns. Build the responsive floating glassmorphism navbar with brand logo, links (Products, Engineering, Company, Blog, Contact), and "Explore Atlas" CTA button, plus mobile menu toggle.
- **acceptance_criteria**:
  - Navbar is fixed/floating with backdrop blur (`backdrop-blur-md`).
  - Mobile responsive drawer/menu works smoothly.
  - All styling uses centralized CSS variables and Tailwind classes.

## Verification Plan
### Automated Tests
- Run `npm run build` to verify TypeScript compilation and bundle success with zero errors.

### Manual Verification
- Verify navbar responsiveness across desktop and mobile breakpoints.
- Inspect CSS variables in browser inspector to confirm dark mode palette consistency.
